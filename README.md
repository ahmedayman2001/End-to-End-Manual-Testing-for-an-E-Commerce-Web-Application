# End-to-End-Manual-Testing-for-an-E-Commerce-Web-Application
A complete, end-to-end manual QA project performed on the e-commerce practice website AutomationExercise.com. The project covers the full testing lifecycle: test planning, test case design, test execution, bug reporting, traceability, and reporting, all managed in Jira with Zephyr (SmartBear Test Management).
